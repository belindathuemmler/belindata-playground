# The Binomial Formulas in Pictures

Article: [https://belindata.com/projects/binomial.html](https://belindata.com/projects/binomial.html) (coming soon)

- `binomial_card.py`: Card image for 'The Binomial Formulas Are Pictures': (a+b)^2 put together, (a-b)^2 cut out with the corner given back, (a+b)(a-b) rearranged.
- `card_binomial.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
