# Playing With Knots

Article: [https://belindata.com/projects/knot-twins.html](https://belindata.com/projects/knot-twins.html) (in progress)

- `knots.html`: the interactive from the article as a standalone page. Open it in any browser, no installation needed.
- `reidemeister_card.py`: Card image for the Reidemeister moves: twist (I), poke (II) and slide (III), each shown as 'before <-> after'. Over-strands get an ivory halo so that the under-strand appears broken.
- `knot_moves_check.py`
- `card_reidemeister.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
