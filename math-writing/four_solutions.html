Four Solutions, One Correct

Four students solved \(x^2 = 4\). Only one solution passes both tests: every line is a statement, and every statement is true. Guess first, then reveal the corrections.

Solution 1 · scribbled
\(x^2 = 4\)
\(= \sqrt{4}\)
\(= 2\)
Solution 1 · scribbled
\(x^2 = 4\)
read aloud: 4 = 2?
\(= \sqrt{4}\)
\(= 2\)
and where is −2?
not one line is a statement: nothing to check, only something to guess
✗ No statements at all.
Solution 2 · square root
Let \(x \in \mathbb{R}\). Then:
\(x^2 = 4\)
\(\Leftrightarrow\; \sqrt{x^2} = \sqrt{4}\)| \(\sqrt{\;\cdot\;}\)
\(\Leftrightarrow\; x = 2\)
Solution 2 · square root
Let \(x \in \mathbb{R}\). Then:
\(x^2 = 4\)
\(\Leftrightarrow\; \sqrt{x^2} = \sqrt{4}\)| \(\sqrt{\;\cdot\;}\)
careful: √(x²) = |x|, not x
\(\Leftrightarrow\; x = 2\)
|x| = 2 ⇔ x = 2 or x = −2. One solution lost, the last ⇔ is false.
✗ Every line a statement, but one of them is false.
Solution 3 · which world?
\(x^2 = 4\)
\(\Leftrightarrow\; x^2 - 4 = 0\)
\(\Leftrightarrow\; (x-2)(x+2) = 0\)
\(\Leftrightarrow\; x = 2\) or \(x = -2\)
Solution 3 · which world?
which x? Introduce it first: Let x ∈ ℝ.
\(x^2 = 4\)
\(\Leftrightarrow\; x^2 - 4 = 0\)
\(\Leftrightarrow\; (x-2)(x+2) = 0\)
\(\Leftrightarrow\; x = 2\) or \(x = -2\)
for x ∈ ℕ the answer would be x = 2 only
✗ Correct steps, but no statement until x is introduced.
Solution 4 · written

\(x^2 = 4\)
\(\Leftrightarrow\; x^2 - 4 = 0\)| \(-\,4\)
\(\Leftrightarrow\; (x-2)(x+2) = 0\)| \(a^2 - b^2 = (a-b)(a+b)\)
\(\Leftrightarrow\; x = 2\) or \(x = -2.\)| \(ab = 0 \Leftrightarrow a = 0 \lor b = 0\)
