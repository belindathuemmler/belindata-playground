Five Solutions, One Perfect

Five solutions of \(x^2 = 4\). Only one passes both tests: every line is a statement (its letters introduced, its link to the line before in place), and every statement is true (the link really holds). And only one would have satisfied my school teacher, Mr B. Guess first, then reveal the corrections: the solution stays as it was handed in, the remarks unfold between the lines.

Solution 1 · scribbled
\(x^2 = 4\)
read aloud: 4 = 2?
\(= \sqrt{4}\)
\(= 2\)
and where is −2?
not one line is a statement: nothing to check, only something to guess
✗ No statements at all.
Solution 2 · square root
Let \(x \in \mathbb{R}\). Then:
\(x^2 = 4\)| \(\sqrt{\;\cdot\;}\)
\(\Leftrightarrow\; \sqrt{x^2} = \sqrt{4}\)
careful: √(x²) = |x|, not x
\(\Leftrightarrow\; x = 2\)
|x| = 2 ⇔ x = 2 or x = −2. One solution lost: this ⇔ is false.
✗ Every line a statement, but one link is false.
Solution 3 · which world?
\(x^2 = 4\)| \(-\,4\)
which x? Introduce it first: Let x ∈ ℝ.
\(\Leftrightarrow\; x^2 - 4 = 0\)| 3rd binomial formula
\(\Leftrightarrow\; (x-2)(x+2) = 0\)| zero-product property
\(\Leftrightarrow\; x = 2\) or \(x = -2\)
for x ∈ ℕ the answer would be x = 2 only
✗ Correct steps, but no statement until x is introduced.
Solution 4 · written
Let \(x \in \mathbb{R}\). Then:
\(x^2 = 4\)| \(-\,4\)
\(\Leftrightarrow\; x^2 - 4 = 0\)| 3rd binomial formula
\(\Leftrightarrow\; (x-2)(x+2) = 0\)| zero-product property
\(\Leftrightarrow\; x = 2\) or \(x = -2\)
✓ every line a statement, every link holds
✓ Passes both tests. One thing left for the bonus level.
