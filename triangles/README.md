# About Fat and Thin Triangles

Article: [https://belindata.com/projects/triangles.html](https://belindata.com/projects/triangles.html) (coming soon)

- `triangles_card.py`: Card image for 'Fat and Thin Triangles': a flat triangle (180°), a fat one on a sphere (270°, three right angles) and a thin one in the hyperbolic plane (less than 180°).
- `card_triangles.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
