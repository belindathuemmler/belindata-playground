# Open the Shell. Which Shell?

Article: [https://belindata.com/projects/shell.html](https://belindata.com/projects/shell.html) (in progress)

- `which_shell.html`: the pretend terminal from the article as a standalone page: enter the Python shell with `python`, leave it with `exit()`, try the classic mistakes. Open it in any browser.
- card image computed by `../cards/shell_api_cards.py`
- `card_shell.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
