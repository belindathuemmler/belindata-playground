# Open the Shell. Which Shell?

Article: [https://belindata.com/projects/shell.html](https://belindata.com/projects/shell.html)

- `language_of_a_shell.html`: the flip cards from the article as a standalone page: what the short words on the command line stand for, in cmd, PowerShell and zsh/bash, three levels; the three decks are aligned, the same place means the same thing. Open it in any browser.
- `which_shell.html`: the fake terminal from the article ("Talking to the Shell") as a standalone page: cmd, PowerShell, zsh or bash, each with its own prompt and error messages; enter the Python shell with `python`, leave it with `exit()`, try the classic mistakes. Open it in any browser.
- card image computed by `../cards/shell_api_cards.py`
- `card_shell.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
