# Open the Shell. Which Shell?

Article: [https://belindata.com/projects/shell.html](https://belindata.com/projects/shell.html)

- `language_of_a_shell.html`: the flip cards from the article as a standalone page: what the short words on the command line stand for, on Windows (cmd, PowerShell) and on Mac/Linux (zsh, bash), three levels. Open it in any browser.
- `which_shell.html`: the fake terminal from the article as a standalone page: enter the Python shell with `python`, leave it with `exit()`, try the classic mistakes. Open it in any browser.
- card image computed by `../cards/shell_api_cards.py`
- `card_shell.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
