# How Parenthood Feels to Me (Sometimes)

Article: [https://belindata.com/projects/parenthood.html](https://belindata.com/projects/parenthood.html) (coming soon)

- `parenthood_card.py`: Card image for 'How Parenthood Feels to Me (Sometimes)': a game screen seen through a parent's eyes, with task cards flying in from all directions, small while far away and large when they arrive, and children shouting in between.
- `card_parenthood.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
