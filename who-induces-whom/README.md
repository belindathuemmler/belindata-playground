# Who Induces Whom?

Article: [https://belindata.com/projects/who-induces-whom.html](https://belindata.com/projects/who-induces-whom.html) (coming soon)

- `who_induces_whom_card.py`: Card image for 'Who Induces Whom?': the chain inner product → norm → metric, each with the formula by which it induces the next.
- `card_who_induces_whom.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
