# Silence = No Questions?

Article: [https://belindata.com/projects/silence.html](https://belindata.com/projects/silence.html) (in progress)

- `any_questions.html`: the interactive from the article as a standalone page. Open it in any browser, no installation needed.
- `silence_card.py`: Card image for 'Silence = No Questions?': a tutor asks "Any questions?", the room stays silent, yet almost everybody has one.
- `card_silence.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
