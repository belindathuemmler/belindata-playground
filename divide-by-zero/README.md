# Never Divide by Zero!

Article: [https://belindata.com/projects/divide-by-zero.html](https://belindata.com/projects/divide-by-zero.html) (coming soon)

- `divide_by_zero_card.py`: Card image for 'Never Divide by Zero!': the classic 'proof' that 2 = 1, with the hidden division by zero.
- `card_divide_by_zero.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
