# About Fat and Thin Matrices

Article: [https://belindata.com/projects/sparse-dense.html](https://belindata.com/projects/sparse-dense.html) (coming soon)

- `sparse_dense_card.py`: Card image for 'About Fat and Thin Matrices': a dense matrix (every entry a number) next to a sparse one (almost all zeros, stored as just a few numbers).
- `card_sparse_dense.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
