# Eigenvalues, Finally Explained

Article: [https://belindata.com/projects/eigenvalues.html](https://belindata.com/projects/eigenvalues.html) (coming soon)

- `eigenvalues_card.py`: Card image for 'Eigenvalues, Finally Explained': left, a matrix bends most directions but only stretches its eigenvectors; right, what the eigenvalue does to the solution e^(λt) of an ODE.
- `card_eigenvalues.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
