# A Car From Above: My First Lesson in 3D Visualization

Article: [https://belindata.com/projects/car-from-above.html](https://belindata.com/projects/car-from-above.html) (coming soon)

- `car_from_above_card.py`: Card image for 'A Car From Above, Taken Literally': left the first-grade drawing (a rectangle, a circle at every corner, a cross in the middle), right the same car in 3D if you take the top view literally: wheels lying flat like plates, and a roof made entirely of window.
- `card_car_from_above.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
