# Measuring on Curved Surfaces

Article: [https://belindata.com/projects/curved-surfaces.html](https://belindata.com/projects/curved-surfaces.html) (in progress)

- `logo_twin_trefoil.py`: belindata logo, rebuilt as mathematics: a ribbon along a trefoil knot, in the logo gradient.
- `moebius_chart_grid.py`: Möbius strip in the belindata logo gradient, with the chart grid (u, v) drawn on it (the former card image).
- `logo_card.py`: Card image: the belindata logo centred in the card format.
- `logo_twin.png`: the image as used on the site
- `card_curved_surfaces.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
