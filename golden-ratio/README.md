# The Golden Ratio Hides in a Pattern

Article: [https://belindata.com/projects/golden-ratio.html](https://belindata.com/projects/golden-ratio.html) (coming soon)

- `fibonacci_card.py`: Card image for 'The Golden Ratio Hides in a Pattern': the Fibonacci substitution a -> ab, b -> a, drawn as rows of long (a, length φ) and short (b, length 1) tiles.
- `card_golden_ratio.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
