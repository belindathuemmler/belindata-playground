# Convergence: Yay, We Will Get There! But When?

Article: [https://belindata.com/projects/convergence.html](https://belindata.com/projects/convergence.html) (coming soon)

- `convergence_card.py`: Card image: the view from the back seat of a car: arms thrown up, the child asking “are we there yet?”, and a dead-straight road to a destination an unguessable distance away.
- `card_convergence.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
