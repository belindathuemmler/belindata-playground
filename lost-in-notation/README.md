# Lost in Notation: A Mathematician Reads Physics

Article: [https://belindata.com/projects/lost-in-notation.html](https://belindata.com/projects/lost-in-notation.html) (coming soon)

- `lost_in_notation_card.py`: Card image for 'Lost in Notation: A Mathematician Reads Physics': one vector written twice, as the column vector (0, 1) the way I write it and as the qubit state |1> the way physicists do.
- `card_lost_in_notation.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
