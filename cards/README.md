# Shared card scripts

Scripts that draw several card images at once. Usage: `python <script> <output folder>`.

| Script | Cards |
|---|---|
| `coming_soon_cards.py` | embeddings; first versions of isoperimetric, math-writing and me-vs-ai (all since replaced by their own scripts) |
| `shell_api_cards.py` | shell, api |
| `ode_numerics_cards.py` | ode-haystack, numerics-exam |
