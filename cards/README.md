# Shared card scripts

Scripts that draw several card images at once. Usage: `python <script> <output folder>`.

| Script | Cards |
|---|---|
| `coming_soon_cards.py` | isoperimetric, embeddings; first versions of math-writing and me-vs-ai (both since replaced by their own scripts) |
| `shell_api_cards.py` | shell, api |
| `ode_numerics_cards.py` | ode-haystack, numerics-exam |
