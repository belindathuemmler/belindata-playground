# This Website, Technically Explained

Article: [https://belindata.com/projects/this-website.html](https://belindata.com/projects/this-website.html)

- `koch_curve_taken_apart.html`: an excerpt of the Koch curve interactive (curve, next step, step back) with the code behind it shown live next to it: the rule a button triggers and the list of points of the one SVG line. Open it in any browser.
- `this_website_card.py`: Card image for 'This Website, Technically Explained': the folder of the website as a tree of files, with the list of cards, `projects.js`, picked out in colour.
- `card_this_website.jpg`: the image as used on the site

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
