# = or ⇔? Nerdy, but It Matters

Article: [https://belindata.com/projects/equals-iff.html](https://belindata.com/projects/equals-iff.html) (coming soon)

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
