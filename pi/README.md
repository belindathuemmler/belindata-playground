# What π Actually Is

Article: [https://belindata.com/projects/pi.html](https://belindata.com/projects/pi.html) (in progress)

- `pi_card.py`: the card image: a circle of diameter 1, its circumference is π (until 3 November 2026 the hexagon picture with 3 < π < 2√3)
- `card_pi.jpg`: the image as used on the site
- `double_the_corners.html`: interactive "Double the Corners": a circle of diameter 1 with a regular polygon inside and one outside; double the corners from 6 to 96 and watch the perimeters n·sin(π/n) and n·tan(π/n) close in on π. Standalone page, open it in any browser.

Python scripts need `numpy` and `matplotlib` (`pip install -r ../requirements.txt`).
